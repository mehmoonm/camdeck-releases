# CamDeck releases

Download CamDeck from [Releases](../../releases/latest):

* **Windows:** `CamDeck-windows-x64.zip` — unzip and run `camdeck.exe`.
* **Android phones:** `CamDeck-android-arm64.apk`.
* **Older phones and most TV boxes:** `CamDeck-android-arm32.apk`.

Installed copies update themselves (Settings → Check now).

The apps are built here by the **Build and release** workflow (Actions tab →
Build and release → Run workflow, with a version such as `v1.9.0`). It
builds from the private source repository; no source code is stored here.
